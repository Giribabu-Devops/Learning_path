components:
providers- platform ands services and plugins are called as providers terraform is be part harshicorp witjput providerswe con't do anything
Example : providers azurerm

terraform {
  required_providers {
    azurerm = {
      source  = "hashicorp/azurerm"
      version = "=2.46.0"
    }
  }
}

resources- resource will define infrastructure objects Vnet,VMs,resource_group etc...

#create resource group
resource "azurerm_resource_group" "rg" {
    name     = "test"
    location = "westus"
    tags      = {
        Environment = "dev"
    }
}

variables- we can use variables to makes our deploymets more dynamic and reusable in to mutiple places

variable "location" {
    type = string
    description = "serve location"
}


variable "system" {
    type = string
    description = "name of the system Environment"

}
